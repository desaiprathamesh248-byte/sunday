OUR BEAUTIFUL MEMORIES — 15 SLIDE WEBSITE

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder "family_surprise_15_slides".
3. Double-click index.html, or right-click it and choose Open with Chrome.
4. Use Next / Back or the dots to move between slides.
5. On slide 14, tap "Tap to reveal" to open the surprise message.
6. Tap Music to play or stop the gentle original melody.

FILES
- index.html: all 15 slide/page sections and photo placements
- style.css: design, transitions, animations and responsive layout
- script.js: slide navigation, surprise envelope and music
- assets/photo1.jpg ... photo7.jpg: your uploaded photos

EDITING TEXT
Open index.html in VS Code and change the text inside each section.
Each slide is a <section class="slide"> block with data-slide="0" through "14".
The 7 uploaded photos are reused in a few slides to fill all 15 slides.

EDITING PHOTOS
Replace an image file in assets while keeping the same filename, for example photo1.jpg.
Or change the src path in index.html to another image filename.

NOTE
The background melody is generated by the browser using Web Audio. It is not an uploaded song.
Internet is only needed to load the optional Google Fonts; the site itself works offline with fallback fonts.
